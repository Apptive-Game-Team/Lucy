# 마지막 야간 순회 — 탐색·가독성 개선

2026-10-19. 에셋 통합 뒤의 두 번째 개발 작업.

## 바뀐 플레이

- 입원 병동의 3개 침상과 가림막·카트, 간호실의 카운터·약장·휴게석, 설비실의 보관함·안전선, 기록실의 서류장·휠체어, 출구의 대기석·유도선을 배치했다. 추가 충돌은 가구의 실제 그림 경계를 사용하며 조사 행과 중앙 도주 통로를 비운다.
- 손전등·팔찌·퓨즈를 획득하면 해당 물건과 조사 안내가 사라진다. 완료한 일회성 조사는 가까운 상호작용 후보에서 제외한다. 기록은 J로 다시 읽는다. 회로와 최종 전력 선택은 계속 변경할 수 있다.
- 배전반에 움직이는 스위치와 ON/OFF 글자를 표시한다. 색에만 의존하지 않는다. 설비 구역 HUD에는 실제 공급 중인 회로 수를 `1/2`, `2/2`로 표시하며 E 안내도 켜기/끄기를 구분한다.
- 현재 구역과 증거 열기 키를 HUD에 표시한다. 추격 경고는 오른쪽 별도 영역에 표시하여 전력 정보와 겹치지 않고, 적이 접근하는 좌우 방향을 안내한다.
- 카메라는 맵 양끝에서 빈 바깥 공간을 보지 않도록 제한하고, 수평 2단위 안의 작은 움직임에는 반응하지 않는다. 사건 저장을 불러오면 카메라를 즉시 복구 위치에 맞춘다.

완료 표시와 회로 정보는 `NightRoundState`에서 파생한다. 저장 형식은 바꾸지 않으며 별도 UI 상태를 저장하지 않는다. 기존 두 결말과 사건 선행조건은 유지한다.

## 검증 방법

`story-art-check` 자동화 명령은 현재 Editor에서 프로젝트 검사·아틀라스 검사와 두 결말의 가상 키보드 완주를 연속 실행한다. 테스트 전 사건 저장을 백업하고 종료 시 복구한다. 위치·인벤토리·진행 상태는 주입하지 않는다. 새 완료 표시와 회로 상태·저장 복원에 대한 상태 검사를 추가했다.

로그: `Logs/NightRoundArtValidation.txt`, `Logs/NightRoundPlaytest-together.txt`, `Logs/NightRoundPlaytest-alone.txt`. 중간 화면: `Logs/NightRoundRefinement-ward.png`, `Logs/NightRoundRefinement-service.png`.
