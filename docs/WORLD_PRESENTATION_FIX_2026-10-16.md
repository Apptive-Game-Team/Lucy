# 월드 아이템·상호작용 안내·시작 병실 수정

- 월드 손전등 프리팹은 테스트 캐릭터 그림을 참조했고 일부 다른 월드 아이템은 스프라이트 참조가 누락돼 있었다. ItemObject에서 ItemData 아이콘 또는 기존 정상 리소스를 사용하는 시각 자식을 생성한다. 최장변을 0.45~0.85 월드 단위로 제한하고 비율을 유지하며 원래 콜라이더와 트리거는 유지한다. 숨겨진 아이템이 나중에 활성화되어도 기존 Lit 재질을 이어받는다.
- 물체 위의 중복 키 문구를 없애고 하단 HUD에 단일 대상을 표시한다. 표시 대상과 키 입력 대상을 공유하며, 가방·일시정지·대화 중에는 안내를 숨긴다. 꺼낸 아이템은 우선하되 수납 불가 아이템은 문과 기록을 가리지 않는다. 서랍을 열면 ‘서랍에서 손전등 꺼내기’로 안내한다. 기록의 월드 표식에는 키 문구를 붙이지 않는다.
- 첫 스폰 병실의 침대와 서랍 주변에만 약한 Point Light2D 두 개를 추가했다. 전역광을 높이지 않고 부드러운 가장자리로 방 안을 비춘다. 타겟 sorting layer를 프리팹에 직렬화하여 standalone에도 적용한다.

## 실제 입력 검증

Unity 새 게임에서 시작 병실 조명과 단일 하단 안내를 확인했다. E로 기록을 읽고 닫은 뒤 서랍까지 이동하여 서랍을 열었다. 월드 손전등 그림과 변경된 안내 문구를 확인한 뒤 E로 획득했다. 인벤토리에 손전등 1개가 표시됐고 월드 안내는 비활성화됐다. 손전등을 장착하고 가방을 닫은 뒤 E로 중앙 문을 열고 북쪽 방(y=2.35)까지 실제 이동했다. 이 수정 이후 전체 엔딩 경로를 다시 완주한 것은 아니다.

## 계단과 손전등 가시성 후속 수정
