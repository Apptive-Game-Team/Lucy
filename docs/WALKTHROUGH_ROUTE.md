# Lucy 실제 입력 플레이 경로

## 검증 범위

활성 씬 YAML·프리팹·스크립트의 정적 분석으로 작성한 경로를 바탕으로, 2026-10-16 실제 키 입력으로 새 게임부터 엔딩까지 검증했다. 기록 4개와 교량 스위치 6개를 모두 완료했으며, 사망 후 최근 기록에서 계속하는 체크포인트도 사용했다. 실행 증거와 범위는 [플레이테스트 기록](PLAYTEST_2026-10-16.md)에 구분해 남겼다. 모든 좌표는 월드 XY이며, 아래 좌표는 이동을 안내하는 기준점이지 각 점의 정확한 통과를 기록한 텔레메트리는 아니다. 순간이동, Transform 변경, 포털/퍼즐 메서드 직접 호출은 완주 검증에 사용하지 않았다.

방향키 이동, Z 상호작용, I 인벤토리, Shift 달리기. 손전등을 획득한 뒤 인벤토리에서 장착하고 배터리를 보충한다. 문은 접근 후 Z를 누른다. 교량 스위치는 접촉 자동 작동이며 다리 활성까지 1초 기다린다.

Player 프리팹 이동속도는 130이므로 fixedDeltaTime=0.02일 때 걷기는 약 2.6 unit/sec, 달리기는 약 3.9 unit/sec다. ResumeMovement 이후에는 코드값 150으로 바뀔 수 있어 실제 좌표 관측을 우선한다. 프리팹 루트 scale 0.3, BoxCollider 크기 (2,2), offset (0,-1)이므로 월드 충돌 크기는 약 0.6×0.6이며 중심은 Transform보다 y가 0.3 낮다. 좁은 다리는 발/콜라이더 중심을 맞추고 0.2~0.5초 단위 입력으로 먼저 정렬한다.

## 1. 시작 병동과 계단

시작점 (-0.10,-3.89). 오른쪽 서랍의 월드 좌표는 (2.412,-0.14), 첫 문은 (0,0.50)이다. 먼저 서랍 아래 접근점 (2.41,-1.4)로 이동한다. E로 서랍을 열고 키를 놓았다가 다시 E를 눌러 손전등을 획득한 뒤 I로 가방을 열어 장착한다. 손전등은 초기에는 숨겨져 있다. 기존 (0,-0.14)는 서랍 자식인 손전등의 로컬 좌표였으며, 실제 손전등 월드 위치는 약 (2.412,-0.28)이다. 서랍 월드 위치는 자식 (9.02,-1.441301)과 부모 (-6.6081886,1.3013012)의 합으로 확인했다.

서랍 조사 후 중앙 문으로 돌아와 Z 또는 E를 누르고 북쪽 병동으로 이동한다. 첫 방과 북쪽 방을 잇는 바닥은 x=0, y=0~1의 좁은 구간이다. 북쪽 방에서는 (0,6.5)에서 동쪽 계단 포털 (7.09,6.5)을 목표로 삼는다. 가구 회피는 실제 화면에서 확인해야 한다.

DoorZone 기본값은 `isLocked=0`, `keyId=0`이고 0101_09.18 및 0201에는 잠금/키 오버라이드가 없다. 현재 이 문에 별도 열쇠는 필요하지 않다. 시작 이벤트·대화가 뜨면 Z로 진행한 뒤 움직인다.

0102 도착 (-2.5,-1.5)에서 위층 포털 (3.53,2.07)로 간다. 후보 경로는 (-2.5,0)→(3.5,0)→(3.53,2.07)이지만 계단 콜라이더에 따른 우회 여부는 실제 입력으로 확인한다. 아래쪽 포털 (-2.48,-3.04)은 되돌아가는 문이므로 피한다.

## 2. 0201 허브

도착 (-7,14.5). 동쪽 끝 (10.02,14.63)은 미로, 중앙 아래의 (3.01,7.15)와 (-2,7.15)는 교량 퍼즐의 양쪽 입구다. 교량 진행은 오른쪽→왼쪽→오른쪽 재방문 순서다. 허브 내 세부 이동은 가구·벽 콜라이더를 보며 조정한다. (0,14.5)에서 중앙 아래 (0,7.15)로 접근하는 것을 후보로 삼되 직선 통과를 검증했다고 간주하지 않는다.

**미로 출구의 바리케이드를 없애려면 서쪽 문 이벤트가 필수다.** 중앙 아래에서 문 (-2,1.5)에 접근해 NPC 대화를 약 5초 기다린다. E로 문을 열고 문 서쪽, x<-2 쪽으로 완전히 빠져나가면 NPC 이벤트가 시작된다. 약 6초 동안 이동 잠금과 화면 전환이 끝날 때까지 기다린다. 이후 중앙 통로를 통해 위쪽 동쪽 미로 포털로 이동한다. 기록 3만 얻고 바로 동쪽으로 가면 x≈8.19에서 바리케이드에 막힌다. 0201 씬 재진입 시 이벤트가 다시 생길 수 있으므로 출구가 막히면 이 문부터 확인한다. 이 해제 절차는 실제 입력 진행에서 확인했다.

## 3. 교량: 여섯 스위치를 모두 밟는 순서

| 스위치 | 실제 월드 XY | 활성화되는 연결 |
|---|---|---|
| S1 / ID0 | (-5.34,-0.62) | 오른쪽 입구↔중앙, 입구↔하단, 중앙↔하단의 4개 다리 |
| S2 / ID1 | (12.70,-0.60) | 오른쪽 중앙↔위쪽, 왼쪽 입구↔중앙, 왼쪽 중앙↔위쪽 |
| S3 / ID2 | (12.70,-10.57) | 왼쪽 중앙↔하단↔왼쪽 하단 |
| S4 / ID3 | (-110.65,-11.61) | 왼쪽 하단↔왼쪽 중앙, 오른쪽 중앙↔오른쪽 끝 |
| S5 / ID4 | (-110.60,-0.46) | 오른쪽 끝↔오른쪽 위, 중앙 위↔오른쪽 위 |
| S6 / ID5 | (29.72,10.47) | 왼쪽 중앙↔왼쪽 위 |

좌표는 Switch 부모 (-6.822623,-3.110074)를 자식 위치에 더한 값이다. 스위치 콜라이더는 trigger이며 중력이 0이다. 작은 스위치이므로 플랫폼 중심에 도착한 다음 위 표의 실제 좌표로 접근해야 한다.

1. **오른쪽 첫 방문:** (-6.1,0.4)→S1. 1초 대기 후 바닥 중심 y≈0을 따라 (12,0)→S2. 이어 중앙 수직 다리로 (12,-10)→S3. 되돌아 (12,0)→(-6,0)→출구 (-7.57,0).
2. **허브에서 왼쪽 입구로:** 0201 복귀점 (2,7.15)에서 (-2,7.15) 포털로 이동. 오른쪽 포털에 다시 닿지 않도록 서쪽으로 출발한다.
3. **왼쪽 방문:** (-74,0.5)→(-92,0)→(-92,-11)→(-110,-11)→S4. 1초 대기 후 (-110,0)→S5. 이전 경로를 거꾸로 돌아 (-110,-11)→(-92,-11)→(-92,0)→(-74,0)→출구 (-72.522,0).
4. **허브에서 오른쪽 재진입:** 복귀점 (-0.9,7.15)에서 (3.01,7.15)로 이동.
5. **오른쪽 마지막 방문:** (-6,0)→(12,0)→(29,0)→(29,11)→S6. 상단 오른쪽 플랫폼의 **기록 3 (29,11)**을 읽고 회복과 비상전력을 얻는다. 회수 후 같은 길을 돌아 오른쪽 출구로 복귀한다.

위 연결은 Bridges 프리팹과 씬 오버라이드로 분석했으며, 실제 입력으로 양쪽 재방문과 스위치 6개 활성화·기록 3 회수를 완료했다. 교량 바깥 어둠은 자원 소모가 증가하므로 플랫폼과 다리를 따라가며 배터리/정신력을 확인한다. 교량 활성 상태는 씬 재방문 및 체크포인트 복귀 시 유지된다.

## 4. 미로에서 엔딩

미로 도착 (-7,-4), 목표 엔딩 트리거 (29.98,-3.75). 기록 4를 읽은 뒤 아래 경로를 따른다. MazeFloor 284개에서 계산한 83칸 BFS 경로에 플레이어 충돌체 중심 오프셋을 반영해 Y를 +0.3 보정했다. 좌표는 캐릭터 Transform 기준이다. 이 경로를 바탕으로 실제 입력 엔딩 도달을 완료했다.

```text
(-7,-3.7)
→ (-4,-3.7) → (-4,-0.7) → (-8,-0.7) → (-8,2.3)
→ (5,2.3) → (5,4.3) → (21,4.3) → (21,15.3)
→ (24,15.3) → (24,7.3) → (28,7.3) → (28,-3.7)
→ (30,-3.7) [엔딩 포털 중심 29.98,-3.75]
```

MazeFloor는 단위 격자, MazeWall은 높이 0.5 격자다. 벽 셀 좌표를 그대로 바닥 좌표로 쓰면 잘못된 경로가 나오므로 월드 좌표 변환을 적용해야 한다. 별도 정적 검사에서는 MazeCeiling 382개(1×1), MazeWall 147개(1×2), 플레이어 충돌체 0.6×0.6을 반영해 위 13구간을 0.1단위로 샘플링했고 겹침이 없었다. 이는 실제 입력 검증과 별개의 기하 검사다.

첫 꺾임에서는 반드시 x≈-4까지 간 후 북상한다. x=-4.82에서 북상하면 벽 하단 y=-3.5에 막힌다. 첫 수직 통로의 안전한 캐릭터 x 범위는 약 -4.2~-3.8이므로 시간만으로 도착을 판단하지 말고 실제 위치를 확인한다. 적의 이동은 고정 경로에 포함되지 않는다.

## 실제 플레이 기록 시 남길 증거

- 시작 UI에서 새 게임 클릭, 이동·Z 상호작용·손전등 장착.
- 양쪽 교량 입구 재방문, S1~S6의 다리 활성화와 기록 회수.
- 미로 입구 조건 충족, 위 경로를 실제 이동하여 엔딩 진입.
- 각 구간의 screenshot 또는 입력 결과 및 런타임 오류 유무.
- 실패 시 재시작과 마지막 성공 시점을 구분해서 기록한다. 정적 분석 및 기존 포털 API 스모크를 실제 완주로 표기하지 않는다.
