# 병동 암부 복구

사용자 피드백: 병원이 어두워야 하는데 맵 전체가 밝음.

원인은 HospitalEnvironment가 전역광을 0.38로 강제하던 설정과, 일부 기존 맵의 Unlit 재질이었다. 전역광은 원래 값과 0.015 중 작은 값을 사용하며, 전역광이 없는 씬의 WardAmbient도 0.015로 낮췄다. 월드 SpriteRenderer와 TilemapRenderer에는 Sprite-Lit-Default를 적용해 바닥·벽도 손전등과 국소 조명의 영향을 받도록 했다. UI 재질은 대상이 아니다. 환경 컴포넌트 정리 시 원래 재질을 복구한다.

Unity 실제 새 게임에서 수정 전 재질로는 주변광을 낮춰도 바닥이 밝게 남는 것을 확인했다. Lit 재질 적용 후 첫 병실의 바닥·벽·가구가 어두워지는 것을 화면으로 확인했다. 실제 이동과 조사 입력으로 서랍의 손전등을 획득하고 인벤토리에서 장착한 뒤, 주변 암부와 손전등 조명이 함께 표시되는 것을 확인했다. 이 변경 이후 전체 엔딩 경로를 다시 완주하지는 않았다.
